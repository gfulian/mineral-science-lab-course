Vim — Quick reference

During the computational laboratories you may occasionally need to make a small change directly on CluMiner: for example, changing a SHRINK value, a lattice parameter, or another CRYSTAL input keyword before submitting a calculation.

For these small edits we use Vim, a terminal text editor available on the cluster. The commands reported on this page are those that will be used the most for the work required in Mineral Science.

TipWhy edit small files directly on CluMiner?

For minor changes, editing the input directly on the Linux cluster avoids an unnecessary download–edit–upload cycle and reduces possible problems with Windows line endings.

The essential idea: Vim has modes

When Vim starts, you are normally in Normal mode. In Normal mode, keys are commands.

To type text, enter Insert mode.

To return to Normal mode, press:

Esc
ImportantIf you are unsure what Vim is doing

Press Esc.

If necessary, press it twice.

Open a file

vim mgo_shrink3.d12

Moving around

The arrow keys work and are perfectly acceptable for this course.

Traditional Vim movement keys are:

Key Movement
h left
j down
k up
l right
0 beginning of line
$ end of line
gg beginning of file
G end of file

Display line numbers:

:set number

Hide them again:

:set nonumber

Insert text

Starting from Normal mode:

Command Action
i insert before the cursor
a insert after the cursor
I insert at the beginning of the line
A insert at the end of the line
o open a new line below
O open a new line above

After editing, press Esc.

Replace text

Replace one character

Move the cursor onto the character and press:

r

followed by the replacement character.

For example, to change:

SHRINK
2 2

move to the first 2, press:

r3

and repeat for the second value.

Replace several characters

Press:

R

to enter Replace mode.

Type over the existing text, then press Esc.

Delete, copy and paste

Command Action
x delete character under cursor
dd delete current line
D delete from cursor to end of line
yy copy current line
p paste after current position/line
P paste before current position/line

Duplicate a line with:

yy
p

Undo and redo

Undo:

u

Redo:

Ctrl+r

Search for a keyword

In Normal mode:

/SHRINK

then press Enter.

Use:

n

for the next match and:

N

for the previous match.

Other useful searches are:

/OPTGEOM
/CVOLOPT
/FREQCALC

Replace a word or value

Replace the first occurrence on the current line:

:s/old/new/

Replace every occurrence on the current line:

:s/old/new/g

Replace every occurrence in the file:

:%s/old/new/g

Ask before every replacement:

:%s/old/new/gc
WarningDo not use global replacement blindly

A number or keyword may occur in more places than expected. For changing a single lattice parameter or SHRINK value, direct editing is usually safer.

Save and quit

Save:

:w

Quit:

:q

Save and quit:

:wq

Quit and discard unsaved changes:

:q!

The two commands worth remembering above all others are:

:wq    save and quit
:q!    abandon changes and quit

A typical course workflow

Create a new input from an existing one:

cp mgo_shrink2.d12 mgo_shrink3.d12

Open it:

vim mgo_shrink3.d12

Inside Vim:

/SHRINK

Change:

2 2

to:

3 3

then:

:wq

Inspect the result:

cat mgo_shrink3.d12

The same approach can be used to replace placeholders such as:

<X>
<A0>

when instructed.

Check Windows/Linux line endings

Inside Vim:

:set fileformat?

A normal Linux file should report:

fileformat=unix

If it reports:

fileformat=dos

convert it with:

:set fileformat=unix
:w

Show invisible characters

:set list

Return to the normal view with:

:set nolist

Jump to a line number

For example:

:40

moves to line 40.

Built-in help

:help

Useful examples:

:help substitute
:help :write

Exit help with:

:q

Interactive tutorial

From the Linux shell:

vimtutor

Command Meaning

i insert text
r replace one character
R Replace mode
/text search
n next search result
u undo
:w save
:wq save and quit
:q! quit without saving
